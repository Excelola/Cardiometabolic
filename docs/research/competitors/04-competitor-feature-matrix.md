# Competitor feature matrix

Research date: 7 November 2026. [Evidence register](evidence/README.md). This matrix distinguishes capability approval from incomplete implementation and unapproved refinements. Observations are public-source descriptions, not signed-in tests. Unknown does not mean absent. Benefits and transfer recommendations are inference.

A = approved capability, implementation incomplete; B = approved capability, UX can improve; C = P1 approved, not current P0; D = genuinely new candidate requiring product approval. A/B can coexist. No capability is labelled Already P2 without a confirmed PRD reference.
